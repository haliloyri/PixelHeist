# Background audio

## Heist Adventure — original (2026-09-26)

- Project file: `heist_adventure.ogg` — the heist background music since 26 September 2026.
- Fully synthesised by `tools/build_music.py` (numpy + ffmpeg/libvorbis); no samples or third-party material.
- Upbeat adventure loop: D minor, 128 BPM, 56 bars (~105 s), seamless join. Plays at −25 dB.

The tension loop below is kept in the repository but is no longer played.

## Sci-Fi Sounds — Kenney

- Source: https://kenney.nl/assets/sci-fi-sounds
- Original: `Audio/engineCircular_000.ogg`, Sci-Fi Sounds 1.0
- License: CC0 1.0. Original license included in `sources/Kenney-License.txt`.
- Project file: `drone_motor.ogg`
- Changes: low/high frequency filtering, peak normalization, 0.35-second loop crossfade. Plays at −31 to −28 dB according to fleet activity.

Source files are retained in `sources/`. Rebuild with `python3 tools/prepare_ambience.py` (requires ffmpeg). Godot uses the ready-to-play Ogg files and needs no network or ffmpeg.

The six pickup sounds and two interface sounds are original procedural sounds generated by `tools/build_asmr_audio.py`.

Pickup revision (2026-09-26): six 300 ms soft wooden "tok" notes (felt mallet on a marimba-like bar, G3–G4 pentatonic) replace the earlier high-register magnetic ticks, which were too shrill. Selection and completion sounds are unchanged.
